## 使い方

### ボタンについて

1. `実行`
   - `緑色の三角マークのボタンです。`
   - `作成したプログラムを実際に実行できます。`
   - `表示 ブロックや 入力 ブロックを使用すると結果を確認できます。`

2. `コード化`
   - `紫色のボタンです。`
   - `組み立てたブロックを C 言語のコードとして出力します。`

3. `クリエイト`
   - `水色の斧マークのボタンです。`
   - `各種ブロックを作成できます。`

4. `新規作成`
   - `クリエイトボタンから選択できます。`
   - `変数を作成するための機能です。`
   - `数字から始まる名前など、使用できない名前の場合は決定ボタンが押せません。`

5. `元の位置に戻る`
   - `ピンク色で三角が2つ描かれたボタンです。`
   - `上下ボタンで移動した位置から初期位置へ戻せます。`

6. `上下`
   - `ブロック列を上下に移動できます。`

---

## 定義について

1. `定義`
   - `基本となるブロックです。`
   - `変数を使用する場合は必ず配置してください。`

2. `表示`
   - `指定した変数の値を表示します。`

3. `文字＆変数`
   - `表示ブロック専用です。`
   - `複数連続で追加できます。`
   - `文字列と変数を混在させて表示できます。`

4. `入力`
   - `入力した値を変数へ格納できます。`
   - `想定外の値を入力するとエラーになる場合があります。`

5. `にする`
   - `変数の値を変更するブロックです。`
   - `数値や別の変数を設定できます。`

---

## 注意事項

- `変数名や入力欄には予約語を書かないでください。`
- `記号の使用はできるだけ避けてください。`
- `想定外の値を入力すると正常に動作しない場合があります。`
