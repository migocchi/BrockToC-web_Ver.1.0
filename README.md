使い方: <br>
「ボタン」について<br>
1. 「実行」ボタン: 緑色の三角マークあるやつ。これで実際にどう動くかがわかります。「表示」ブロックや「入力」ブロックなど使うと何かでてきます。
2. 「コード化」ボタン:  紫色のやつ。組んだブロックのプログラムをC言語化してくれます。
3. 「クリエイト」ボタン: 水色の斧のマークあるやつ。これ押すと、ブロックがいろいろ出てきます。
4. 「新規作成」ボタン: 「クリエイト」ボタン押すとでてきます。変数を作るのに使います。数字を最初に書いたりなど、禁止されているものをかくと、決定が押せないときがあります。
5. 「元の位置に戻る」ボタン: ピンクで三角が二つあるやつ。「上下」ボタンで移動した位置から、初期位置に戻ることができます。
6. 「上下」ボタン: ブロック列の位置を上下に移動することができます。

「定義」について<br>
1. 「定義」ブロック: これがないと基本何も起きません。変数を使いたいときは、必ずこのブロックを置いてください。
2. 「表示」ブロック: これに入れた変数の値を表示できます。
3. 「文字＆変数」チップ: これは「表示」ブロックにのみ入れられます。連続してつけることが可能です。これにより、変数を入れることも、途中に文字を書くこともできます。
4. 「入力」ブロック: 書いた文字の値を変数に格納できます。コードを実行する際は、違うことを入力するとエラーが起きるかもしれません。
5. 「にする」ブロック: 変数の値を変えるブロック。変数を持ってくることも、実際に書くこともできます。

注意事項: <br>
- 文字を入力する際、予約語を書かないでください。
- 文字を入力する際、記号の使用は控えてください。
